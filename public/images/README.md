# 📸 Библиотека изображений

Эта папка содержит SVG-изображения для всех материалов проекта в единой стилистике.

## 📁 Структура

```
public/images/
├── articles/          # Обложки для статей
│   ├── nutrition.svg      # Нутрициология (зеленый)
│   ├── psychology.svg     # Психология (фиолетовый)
│   ├── wellness.svg       # Wellness (синий)
│   └── lifestyle.svg      # Образ жизни (оранжевый)
│
├── videos/            # Превью для видео
│   ├── nutrition.svg      # Нутрициология
│   ├── psychology.svg     # Психология
│   ├── wellness.svg       # Wellness
│   └── gymnastics.svg     # Гимнастика (розовый)
│
├── webinars/          # Обложки для вебинаров
│   └── default.svg        # Универсальная обложка
│
├── services/          # Изображения для услуг
│   ├── nutrition.svg      # Консультация нутрициолога
│   ├── health-coaching.svg    # Health-коучинг
│   └── slavic-gymnastics.svg  # Славянская гимнастика
│
├── cases/             # Изображения для кейсов
│   ├── weight-loss.svg    # Снижение веса
│   ├── energy.svg         # Энергия и здоровье
│   └── habits.svg         # Пищевые привычки
│
└── authors/           # Фото авторов
    └── ksenia-kamenskaya.svg  # Ксения Каменская
```

## 🎨 Цветовая схема

Каждая категория использует свой фирменный цвет:

| Категория | Цвет | Градиент |
|-----------|------|----------|
| Нутрициология | Зеленый | `#10B981 → #047857` |
| Психология | Фиолетовый | `#7C3AED → #5B21B6` |
| Wellness | Синий | `#3B82F6 → #1D4ED8` |
| Образ жизни | Оранжевый | `#F97316 → #C2410C` |
| Гимнастика | Розовый | `#EC4899 → #BE185D` |

## 🖼️ Стиль изображений

Все изображения выполнены в едином стиле:
- **Фон**: градиент категории
- **Центральный элемент**: минималистичная иконка по теме
- **Декоративные элементы**: полупрозрачные круги для глубины
- **Текст**: название категории (для некоторых изображений)

## 📝 Использование

### В статьях:
```tsx
<Image
  src={`/images/articles/${article.category}.svg`}
  alt={article.title}
  fill
  className="object-cover"
/>
```

### В видео:
```tsx
<Image
  src={`/images/videos/${video.category}.svg`}
  alt={video.title}
  fill
  className="object-cover"
/>
```

### В услугах:
```tsx
<Image
  src={`/images/services/${service.slug}.svg`}
  alt={service.title}
  fill
  className="object-cover"
/>
```

## ➕ Добавление новых изображений

1. Создайте SVG-файл в соответствующей папке
2. Используйте градиент категории
3. Добавьте минималистичную иконку по центру
4. Размер: 800x600px для обложек, 400x400px для авторов

## 🔄 Генерация

Все изображения созданы в формате SVG для:
- ✅ Масштабируемости без потери качества
- ✅ Малого размера файла
- ✅ Быстрой загрузки
- ✅ Поддержки темной темы (при необходимости)
