## Формат Документов

Каждый документ `.md` должен следовать формату Gray Matter:

```markdown
---
slug: contract
title: Договор оферты
description: Публичная оферта на информационные услуги по нутрициологии и health-коучингу
version: 1.0
lastUpdated: 2026-05-10
category: contract
showInFooter: true
showInIndex: true
order: 1
icon: scale
---

# Текст документа в Markdown
```

### Frontmatter Поля

- **slug** — уникальный ID (совпадает с именем файла)
- **title** — название документа
- **description** — описание (для индекса)
- **version** — версия документа
- **lastUpdated** — дата последнего обновления (YYYY-MM-DD)
- **category** — категория (contract, privacy, consent, policy, info)
- **showInFooter** — показывать в footer (true/false)
- **showInIndex** — показывать на странице /legal (true/false)
- **order** — порядок отображения
- **icon** — иконка (scale, lock, file, etc.)

## Экспериментальный Цикл (6 Итераций)

### Iteration 1: contract.md (Договор оферты)
- Актуализировать для нутрициолога + health-коуча
- Убедиться, что дисклеймер об ответственности четкий
- Указать, что это информационные услуги, не медицинские
- Проверить условия оплаты и возврата

### Iteration 2: privacy-policy.md (Политика конфиденциальности)
- Соответствие 152-ФЗ
- Указать точки сбора данных (Contact Form, Яндекс Метрика)
- Сроки хранения данных
- Права пользователя (доступ, удаление, исправление)

### Iteration 3: personal-data-consent.md (Согласие на ПД)
- Краткое согласие для Contact Form
- Ссылка на Политику конфиденциальности
- Понятный язык для пользователей

### Iteration 4: marketing-consent.md (Согласие на маркетинг)
- Отдельное согласие на рассылку (Закон о рекламе)
- Каналы: email, SMS, Telegram, WhatsApp
- Право отписаться в любой момент

### Iteration 5: return-policy.md (Возврат денежных средств)
- Условия возврата (14 дней, 30 дней)
- Исключения (информационные услуги, коучинговые сессии)
- Процедура возврата

### Iteration 6: delivery-terms.md (Порядок оказания услуг)
- Сроки предоставления услуг
- Процедура консультации
- Обязательства эксперта и клиента
- Связь с условиями договора

## Оценка Legal Compliance

Для каждой итерации оцените:

- **Актуальность для деятельности:** соответствует ли документ нутрициологии + health-коучингу?
- **Соответствие РФ законодательству:** 152-ФЗ, 54-ФЗ, 38-ФЗ, 2300-1?
- **Ясность языка:** может ли обычный пользователь понять документ?
- **Юридическая корректность:** нет ли противоречий или пробелов?

### Scoring (0-100 per document)

```
actual_for_expert_activities: 0-100
rf_legislation_compliance: 0-100
language_clarity: 0-100
legal_correctness: 0-100

document_score = (actual * 0.3 + compliance * 0.4 + clarity * 0.2 + correctness * 0.1) / 100
```
